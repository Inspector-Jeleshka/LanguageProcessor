## Вариант задания

53. Объявление вещественной константы с инициализацией на языке Rust

Примеры верных строк:
- `const PI: f32 = 3.14;`
- `const E:f32=2.71;`
- `const variable : f32 = 123.4;`

## Контекстно-зависимые условия

Реализованы проверки следующих условий:
| Условие | Пример строки | Сообщение |
| -- | :--: | :--: |
| Уникальность идентификаторов | `const pi: f32 = 3.14;`<br>`const pi: f32 = 10.2;` | Повторное объявление идентификатора 'pi' |
| Значение находится в допустимом диапазоне | `const pi: f32 = 111211121112111`<br>`2111211121112111211121112111.3;` | Значение выходит за пределы допустимого диапазона f32 |

*Примечание.*  
Проверки совместимости типов и является ли значение численным литералом не требуют контекста, поэтому выполняются до построения AST.

## Структура AST

a. Описание типов узлов

| Тип узла | Назначение |
| -- | -- |
| `AstNode` | Базовый класс всех узлов дерева. Хранит вид узла, положение во входном тексте и список дочерних узлов. |
| `CompilationUnitNode` | Корневой узел AST, соответствующий всей анализируемой программе. Его дочерними узлами являются объявления констант. |
| `ConstDeclNode` | Узел объявления константы. Содержит имя константы, её тип и значение. |
| `IdentifierNode` | Узел идентификатора, содержащий имя объявляемой константы. |
| `TypeNode` | Узел типа данных. В реализованном варианте используется тип f32. |
| `LiteralNode` | Узел литерального значения константы. Для корректного объявления f32 содержит вещественный литерал вида FloatLiteral. |

c. Формат вывода AST в программе

```
└── CompilationUnit
    └── ConstDecl [name=P, type=f32]
        ├── Identifier [name=P]
        ├── Type [name=f32]
        └── Literal [kind=FloatLiteral, text=3.1]
```
